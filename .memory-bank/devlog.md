# Devlog
A log of all significant tasks completed by the AI agent. 
When the AI agent completes a task, it should add an entry to the devlog.
It should also add entries when the user commands "update devlog" or "update log"

Newest entries at the top.

Format:
```
[timestamp] - [action] - [description]
```

2025-03-27 10:00:00 - [create] - [create devlog.md]
